# Oracle 자연어 → SQL 생성기 PRD

## 1) 목표와 성공조건

### 1.1 목표

Oracle DB에서 수행하고 싶은 작업을 자연어로 입력하면, 사용자가 참고하거나 복사해 사용할 수 있는 **Oracle SQL 쿼리 1개를 생성하는 단일 화면 서비스**를 만든다.

서비스의 핵심 흐름은 아래 3단계로 제한한다.

**자연어 입력 → Oracle SQL 생성 → 결과 복사**

로그인, 결제, 실제 DB 연결, SQL 실행, 저장 기능은 제공하지 않는다.

### 1.2 해결하려는 문제

Oracle SQL 문법에 익숙하지 않은 개발자, 기획자, 운영 담당자는 단순한 조회·생성·수정·삭제 작업도 직접 SQL로 변환해야 한다.

예를 들어 사용자는 아래처럼 원하는 작업 자체는 설명할 수 있다.

* `회원 테이블에서 최근 가입한 10명을 조회해줘`
* `orders 테이블에서 status가 CANCEL인 데이터를 삭제해줘`
* `users 테이블의 user_id가 100인 데이터의 이름을 홍길동으로 수정해줘`

하지만 이를 Oracle SQL 문법으로 직접 작성하는 과정에서 시간이 소요되거나 문법 오류가 발생할 수 있다.

### 1.3 MVP 범위

이번 MVP에서 제공하는 기능은 **자연어 DB 작업 요청을 Oracle SQL로 변환하는 기능 1개**이다.

지원 대상 작업의 대표 범위는 다음과 같다.

* 조회: `SELECT`
* 생성/추가: `INSERT`
* 수정: `UPDATE`
* 삭제: `DELETE`
* 테이블 생성 등 구조 생성: `CREATE`

생성된 SQL은 화면에 텍스트로 보여주기만 하며 실제 DB에서는 실행하지 않는다.

### 1.4 성공조건

다음 조건을 모두 만족하면 MVP가 성공한 것으로 본다.

1. 사용자가 최초 화면 진입 후 **1분 이내에 자연어 입력 → SQL 생성 → 복사**를 완료할 수 있다.
2. 사전에 준비한 대표 자연어 요청 10건 중 **8건 이상에서 사용자의 의도와 일치하는 Oracle SQL 초안이 생성된다.**
3. 별도 로그인이나 초기 설정 없이 즉시 사용할 수 있다.
4. 생성된 결과는 Oracle SQL 형태로 출력된다.
5. 생성된 SQL을 한 번의 동작으로 복사할 수 있다.
6. 오류 상황에서는 사용자가 다음 행동을 알 수 있도록 화면에 오류 문구가 표시된다.

## 2) 사용자 스토리

### 2.1 핵심 사용자

Oracle DB를 사용하지만 SQL 작성에 익숙하지 않거나, 간단한 SQL 초안을 빠르게 만들고 싶은 사용자.

대표 사용자는 다음과 같다.

* 개발자
* 서비스 기획자
* 운영 담당자
* 데이터 조회 업무를 수행하는 실무자

### 2.2 핵심 사용자 스토리

**US-01**
사용자로서
내가 원하는 DB 작업을 자연어로 입력하고 싶다.
그래야 Oracle SQL 문법을 직접 작성하지 않아도 된다.

**US-02**
사용자로서
자연어 입력 후 `SQL 생성` 버튼을 누르면 Oracle SQL을 받고 싶다.
그래야 업무에 필요한 SQL 초안을 빠르게 얻을 수 있다.

**US-03**
사용자로서
생성된 SQL을 화면에서 명확하게 확인하고 싶다.
그래야 실행 전에 내용을 검토할 수 있다.

**US-04**
사용자로서
생성된 SQL을 바로 복사하고 싶다.
그래야 별도의 드래그나 선택 없이 다른 도구에 붙여넣을 수 있다.

**US-05**
사용자로서
내 입력이 잘못되었거나 SQL 생성에 실패했을 때 이유를 알고 싶다.
그래야 입력을 수정하거나 다시 시도할 수 있다.

**US-06**
사용자로서
데이터를 수정하거나 삭제할 가능성이 있는 SQL에는 경고를 보고 싶다.
그래야 위험한 SQL임을 인지한 상태에서 사용할 수 있다.

## 3) 화면 명세

### 3.1 화면 구성

서비스는 **단일 화면 1개**로 구성한다.
별도 페이지 이동, 메뉴, 설정 화면은 만들지 않는다.

화면 요소는 위에서 아래 순서로 다음과 같이 배치한다.

| 순서 | 화면 요소 | 설명 |
| --- | --- | --- |
| 1 | 서비스 제목 | 서비스가 자연어를 Oracle SQL로 변환한다는 목적을 표시 |
| 2 | 안내 문구 | 어떤 형태로 입력하면 되는지 짧게 설명 |
| 3 | 자연어 입력창 | 사용자가 원하는 DB 작업을 입력 |
| 4 | 입력 오류 문구 영역 | 입력값 검증 실패 시 빨간색 오류 문구 표시 |
| 5 | `SQL 생성` 버튼 | 입력 내용을 기반으로 SQL 생성 요청 |
| 6 | 생성 상태 영역 | 생성 중임을 사용자에게 표시 (`SQL을 생성하고 있습니다.`) |
| 7 | 결과 오류 문구 영역 | 생성 실패 또는 결과 이상 시 빨간색 오류 문구 표시 |
| 8 | 위험 SQL 경고 영역 | 수정·삭제 등 위험 가능성이 있는 SQL에서 표시 |
| 9 | SQL 결과 영역 | 생성된 Oracle SQL 표시 |
| 10 | `복사` 버튼 | 생성된 SQL 전체를 복사 |

### 3.2 최초 진입 상태

사용자가 처음 화면에 진입했을 때 다음 상태로 표시한다.

* 자연어 입력창: 빈 상태
* SQL 생성 버튼: 표시 (활성화)
* 오류 메시지: 표시하지 않음
* SQL 결과 영역: 결과 없음
* 복사 버튼: 비활성화 또는 숨김
* 위험 SQL 경고: 표시하지 않음

### 3.3 자연어 입력창

* 사용자가 DB 작업을 문장 형태로 입력할 수 있다.
* 예시 placeholder: `예: orders 테이블에서 status가 CANCEL인 데이터를 삭제해줘`
* 여러 단어와 문장을 입력할 수 있어야 한다.
* 입력 내용은 사용자가 직접 수정할 수 있어야 한다.

### 3.4 SQL 생성 버튼

* 버튼 텍스트는 **`SQL 생성`**으로 고정한다.
* 버튼 클릭 시 먼저 입력값을 검증한다.
* 입력값이 유효하지 않으면 AI 요청을 보내지 않고 오류 메시지를 표시한다.
* 입력값이 유효한 경우에만 SQL 생성을 요청한다.
* 생성 요청이 진행 중인 동안 중복 요청을 방지하기 위해 SQL 생성 버튼을 일시적으로 비활성화한다.

### 3.5 생성 중 상태

* SQL 생성 요청이 시작되면 결과가 반환되기 전까지 사용자에게 처리 중임을 알린다.
* 표시 문구 예시: **`SQL을 생성하고 있습니다.`**
* 생성 중에는 이전 오류 메시지를 제거한다.

### 3.6 SQL 결과 영역

정상 결과를 받으면 SQL 결과 영역에 생성된 Oracle SQL을 표시한다.

결과 영역에서는 다음을 만족해야 한다.
* 일반 설명보다 SQL 자체를 우선 표시한다.
* SQL의 줄바꿈을 유지한다.
* 사용자가 전체 SQL을 읽을 수 있다.
* 결과 텍스트를 수정하는 편집 기능은 제공하지 않는다.
* SQL을 실제 실행하는 버튼은 제공하지 않는다.

### 3.7 복사 버튼

* 정상 SQL 결과가 존재할 때만 사용할 수 있다.
* 버튼 텍스트: **`복사`**
* 버튼을 누르면 결과 영역에 표시된 SQL 전체를 클립보드에 복사한다.
* 복사 성공 후 짧은 피드백을 표시한다: **`복사되었습니다.`**

### 3.8 위험 SQL 경고

생성 결과에 다음과 같이 데이터를 변경하거나 삭제할 가능성이 높은 명령이 포함된 경우 경고를 표시한다.
* `UPDATE`, `DELETE`, `DROP`, `TRUNCATE`, `ALTER`
* 경고 문구 예시: **`주의: 이 SQL은 데이터를 수정하거나 삭제할 수 있습니다. 실행 전에 반드시 내용을 확인하세요.`**
* 경고는 SQL 실행을 차단하기 위한 기능이 아니다. (본 서비스는 SQL 실행 기능 미제공)

## 4) 기능 명세

### 4.1 기능 F-01: 자연어 입력
사용자는 하나의 입력창에 원하는 Oracle DB 작업을 자연어로 입력한다. 입력값은 SQL 생성 요청의 유일한 사용자 입력값으로 사용한다.

### 4.2 기능 F-02: 입력값 검증
`SQL 생성` 버튼을 누르면 입력값이 정상적인 DB 작업 요청인지 기본 검증한다.
* 입력값이 비어 있는지
* 공백만 입력되었는지
* 입력값이 지나치게 짧은지 (예: 2자 미만)
* 입력값이 지나치게 긴지 (예: 500자 초과)
검증 실패 시 SQL 생성 요청을 진행하지 않는다.

### 4.3 기능 F-03: Oracle SQL 생성
* Oracle SQL 문법을 사용한다.
* 사용자가 요청한 작업과 최대한 일치하는 SQL 1개를 생성한다.
* SQL이 핵심 결과가 되어야 한다.
* MySQL, PostgreSQL, MSSQL 전용 문법 사용을 피한다.
* 사용자가 제공하지 않은 실제 DB 스키마가 존재한다고 보장하지 않는다.
* 알 수 없는 테이블·컬럼 정보를 실제 DB에서 조회하지 않는다.
* SQL을 실제 실행하지 않는다.

### 4.4 기능 F-04: 결과 표시
* 정상 응답을 받으면 기존 결과를 새 결과로 교체한다.
* 새로운 요청 시 이전 결과 대신 새로운 결과를 표시한다 (대화 누적 X).

### 4.5 기능 F-05: SQL 복사
* 정상적으로 생성된 SQL 전체를 복사할 수 있다.
* 오류 문구, 경고 문구, 설명 문구는 복사 대상에 포함하지 않는다.

### 4.6 기능 F-06: 위험 SQL 경고
생성 결과가 데이터를 변경하거나 삭제할 가능성이 있는 작업이라면 경고를 표시한다. (단, 차단/수정하지 않음)

### 4.7 만들지 않는 기능 (Out of Scope)
* 로그인, 회원가입, 계정 관리
* 결제, 구독, 과금 관리
* 실제 Oracle DB 연결 및 접속 정보 입력
* SQL 실행 및 실행 결과 표시
* DB 스키마 자동 조회 / 탐색
* Oracle Parser 기반 엄격 문법 검사 / 실행 가능 여부 검증
* SQL 성능 분석 / 실행계획 / 인덱스 추천 / 자동 튜닝
* SQL 히스토리 / 즐겨찾기 / 사용자별 저장
* 멀티턴 대화 / 컨텍스트 유지 / 후속 질문 수정
* MySQL, PostgreSQL, MSSQL 등 기타 DBMS 지원

## 5) 예외 처리

### 5.1 공통 원칙
* 오류 문구는 입력창 또는 결과 영역에서 바로 인지할 수 있는 위치에 표시한다.
* 오류 문구 색상은 **빨간색**으로 표시한다.
* 한 번의 요청에서 가장 우선순위가 높은 오류 메시지 1개를 표시한다.
* 오류가 발생한 경우 잘못된 결과를 정상 SQL처럼 표시하지 않는다.
* 사용자가 입력값을 수정하거나 다시 `SQL 생성` 버튼을 누르면 이전 오류 상태를 초기화하고 다시 검증한다.

### 5.2 예외 코드 및 메시지 매핑

| 코드 | 발생 조건 | 오류 문구 (빨간색) |
| --- | --- | --- |
| **E-01** | 입력값이 비어 있음 (공백, 줄바꿈만 포함된 경우 포함) | `내용을 입력해주세요` |
| **E-02** | 입력값이 너무 짧음 (예: '조회', '삭제' 등 최소 기준 미달) | `올바른 내용을 입력해주세요` |
| **E-03** | 입력값이 너무 김 (문서, 로그 등 MVP 허용 최대 길이 초과) | `올바른 내용을 입력해주세요` |
| **E-04** | AI 응답 자체가 실패함 (네트워크 에러, 서버 에러 등) | `다시 시도해 주세요` |
| **E-05** | 응답 시간이 10초 이상 걸림 (타임아웃) | `올바른 내용을 입력해주세요` |
| **E-06** | AI 응답에 정상적인 SQL이 없음 (설명만 반환 등) | `올바른 DB 작업 기능인 조회/수정/삭제/생성 등의 기능의 단어가 포함되어 있는지 확인해 주세요` |
| **E-07** | 입력 내용이 DB 작업으로 판단하기 어려움 (일상 대화 등) | `올바른 DB 작업 기능인 조회/수정/삭제/생성 등의 기능의 단어가 포함되어 있는지 확인해 주세요` |
| **E-08** | 요청의 대상 정보가 부족함 (예: '데이터를 삭제해줘') | `올바른 DB 작업 기능인 조회/수정/삭제/생성 등의 기능의 단어가 포함되어 있는지 확인해 주세요` |
| **E-09** | 다른 DBMS 문법을 명시적으로 요청함 (MySQL, PG 등) | `Oracle DB 작업 내용을 입력해주세요` |
| **E-10** | 결과가 위험한 SQL인 경우 (`UPDATE`, `DELETE`, `DROP` 등) | `주의: 이 SQL은 데이터를 수정하거나 삭제할 수 있습니다. 실행 전에 반드시 내용을 확인하세요.` (정상 SQL과 함께 경고 표시) |
| **E-11** | 복사할 결과가 없음 | 복사 버튼 비활성화 / 숨김 |
| **E-12** | 클립보드 복사 동작 실패 | `복사하지 못했습니다. 다시 시도해 주세요` |

### 5.3 예외 메시지 우선순위 (5.13)
1. 입력값 없음 (E-01)
2. 입력값 길이 오류 (E-02, E-03)
3. DB 작업과 관계없는 입력 (E-07)
4. 다른 DBMS 요청 (E-09)
5. 요청 대상 정보 부족 또는 결과 이상 (E-06, E-08)
6. AI 응답 실패 (E-04)
7. 10초 시간 초과 (E-05)
8. 복사 실패 (E-12)

### 5.4 오류 상태 초기화 규칙 (5.14)
* **입력값 수정 시**: 기존 입력 관련 오류 문구 제거, 기존 SQL 결과 초기화
* **SQL 생성 버튼 클릭 시**: 이전 AI 응답 오류 제거, 로딩 상태 진입
* **새로운 정상 결과 생성 시**: 모든 이전 오류 제거, 새 결과 및 위험 SQL 경고 표시

### 6.1 화면
- [ ] 화면이 하나만 존재한다.
- [ ] 자연어 입력창이 존재한다.
- [ ] `SQL 생성` 버튼이 존재한다.
- [ ] SQL 결과 영역이 존재한다.
- [ ] `복사` 버튼이 존재한다.
- [ ] 오류 메시지를 표시할 영역이 존재한다.
- [ ] 위험 SQL 경고를 표시할 영역이 존재한다.

### 6.2 핵심 기능
- [ ] 사용자가 자연어 DB 작업을 입력할 수 있다.
- [ ] `SQL 생성` 버튼 클릭 시 Oracle SQL 생성을 요청한다.
- [ ] 정상 결과는 SQL 결과 영역에 표시된다.
- [ ] 새 요청 성공 시 이전 결과가 새 결과로 교체된다.
- [ ] 생성된 SQL을 복사할 수 있다.
- [ ] 실제 SQL 실행 기능은 존재하지 않는다.

### 6.3 입력 예외
- [ ] 입력이 비어 있으면 `내용을 입력해주세요`가 빨간색으로 표시된다.
- [ ] 입력이 너무 짧으면 `올바른 내용을 입력해주세요`가 빨간색으로 표시된다.
- [ ] 입력이 너무 길면 `올바른 내용을 입력해주세요`가 빨간색으로 표시된다.
- [ ] DB 작업과 관계없는 입력은 정상 SQL 결과로 처리하지 않는다.
- [ ] Oracle 외 DBMS 요청은 정상 Oracle SQL 요청과 구분한다.

### 6.4 생성 예외
- [ ] AI 응답 실패 시 `다시 시도해 주세요`가 빨간색으로 표시된다.
- [ ] 요청 후 10초 이상 응답이 없으면 시간 초과 상태로 처리한다.
- [ ] 시간 초과된 이전 요청의 늦은 응답이 최신 결과를 덮어쓰지 않는다.
- [ ] SQL이라고 판단하기 어려운 결과는 성공 상태로 표시하지 않는다.
- [ ] 결과가 이상한 경우 `올바른 DB 작업 기능인 조회/수정/삭제/생성 등의 기능의 단어가 포함되어 있는지 확인해 주세요`가 표시된다.

### 6.5 위험 SQL
- [ ] `UPDATE`가 포함된 결과에 경고를 표시한다.
- [ ] `DELETE`가 포함된 결과에 경고를 표시한다.
- [ ] `DROP`이 포함된 결과에 경고를 표시한다.
- [ ] `TRUNCATE`가 포함된 결과에 경고를 표시한다.
- [ ] `ALTER`가 포함된 결과에 경고를 표시한다.
- [ ] 경고가 있어도 SQL 결과 자체는 확인 및 복사할 수 있다.

### 6.6 범위 제한
- [ ] 로그인 / 회원가입 / 결제 기능 없음
- [ ] 실제 DB 연결 및 SQL 실행 기능 없음
- [ ] SQL 저장 / 히스토리 / 멀티턴 대화 기능 없음
- [ ] 타 DBMS / DB 스키마 자동 조회 / 튜닝 기능 없음
